# 📱 CrewPing v1.1 (실구현 모바일 웹 · Cloudflare 무료 서버리스)

> 기존 포트폴리오 확장판(`../crew-connect/`)은 그대로 보존하고, **1~5명의 승무원과 파트너·부모님·가족이 스마트폰으로 안전하고 직관적으로 쓸 수 있도록 분리된 실서비스 버전**입니다.

---

## 1. 핵심 설계 및 권한 분리 원칙

- **완벽한 화면·권한 분리**:
  - **❤️ 파트너·부모님·가족 공유 페이지 (`/`)**: 오직 상태 확인과 일정 열람만 가능하며, **승무원 페이지로 이동하는 버튼·설정 메뉴·체류비(퍼디엠) 정보가 일절 노출되지 않습니다.**
  - **🧑‍✈️ 승무원 본인 전용 페이지 (`/?mode=crew`)**: 최초 접속 시 **비밀번호(4자리 이상 PIN, 서버 SHA-256 해시 저장)**를 설정하며, 이후 **비밀번호 인증을 통과한 본인만** 접근하여 일정 등록·원터치 상태 알림·체류비 개략 가늠치를 확인할 수 있습니다.
- **최초 접속 온보딩 가이드**:
  - 가상의 샘플 이름이나 가짜 비행 데이터가 노출되지 않으며, 최초 접속 시 사용자 정보(호칭)와 비행 일정(`.ics` 주소 / `.ics` 파일 / 수동 추가)을 등록하도록 직관적으로 안내합니다.
- **인프라 비용 $0**: `Cloudflare Workers + Static Assets + Workers KV + Cron Triggers("*/30 * * * *")`
