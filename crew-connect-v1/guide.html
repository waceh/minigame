모바일 웹 실구현 설계서

포트폴리오 확장판에서 복잡한 부가기능을 과감히 덜어내고, 1~5명의 승무원과 ❤️ 파트너·가족이 스마트폰으로 3초 안에 직관적으로 확인하며 Cloudflare 무료 서버리스($0/월)로 즉시 운영할 수 있도록 구현한 1차 실전 버전 가이드입니다.

01 · Cloudflare 올인원 무료 인프라 Static Assets + Workers API + KV + 30분 Cron Trigger 통합으로 월 유지비 완전 $0 및 요금 폭탄 위험 제로
02 · 모바일 3초 직관 UI (하단 2-Tab) [🟢 지금 상태]와 [📅 이번 달 일정] 딱 두 탭으로 단순화하여 어르신·파트너 누구나 한눈에 파악
03 · OAuth 심사 없는 간편 캘린더 연동 Google Calendar '비공개 iCal(.ics) 주소' 읽기 전용 자동 동기화 + 파일 직접 업로드 지원
04 · 무부담 소통 & 승무원 원터치 알림 가이드 시간 미응답 가능성 상시 고지 및 승무원 본인용 [잘 내렸어 / 이제 잘게 / 잠깐 여유] 3버튼 제공
프로젝트 경로: crew-connect-v1/ (기존 포트폴리오 crew-connect/ 별도 보존) 버전: MVP v1.0 · 2026. 11. 25

SECTION 03 · DEPLOYMENT & OPERATION GUIDE

Cloudflare 5분 무료 배포 및 카카오톡 연동 가이드

CrewPing v1.0 Spec
🚀 1. 로컬 실행 및 Cloudflare 무료 배포 절차
# 1. 폴더 이동 및 패키지 설치
cd /Users/lotte/IdeaProjects/etc/minigame/crew-connect-v1
npm install

# 2. 로컬 개발 서버 테스트 (http://localhost:8787)
npx wrangler dev

# 3. Cloudflare 로그인 및 무료 KV 저장소 생성 (최초 1회)
npx wrangler login
npx wrangler kv namespace create CREW_KV
# -> 출력된 id 값을 wrangler.jsonc의 kv_namespaces[0].id에 붙여넣기

# 4. 공공데이터포털 인천공항 API(#15095074) 인증키 등록 및 배포
npx wrangler secret put DATA_GO_KR_API_KEY
npx wrangler deploy
👥 2. 승무원 1~5명 등록 및 운영 방법 (어드민 개발 불필요)
  • 승무원 추가: 별도 회원가입 화면을 만들 필요 없이, KV에 crew:haneul, crew:minsu 형태로 최대 5개의 JSON 키만 등록해 두면 각각 독립된 URL로 동작합니다.
  • Google Calendar 연결: 승무원 본인의 구글 캘린더 PC 웹 [설정 → 내 캘린더의 설정 → iCal 형식의 비공개 주소] URL을 복사해 1회만 등록하면 이후 스마트폰 기본 캘린더에 일정을 적을 때마다 30분 주기로 자동 반영됩니다.
  • 스마트폰 앱처럼 설치: 배포된 주소를 아이폰 Safari(공유 → 홈 화면에 추가) 또는 갤럭시 Chrome(홈 화면에 추가)으로 등록하면 상단 주소창 없는 깔끔한 전용 앱으로 실행됩니다.
💬 3. 향후 카카오톡 채널 챗봇 연결 (준비 완료)

POST https://<배포도메인>/api/kakao/skill?crew=haneul

src/worker.js에 카카오 i 오픈빌더 v2.0 응답 포맷이 이미 구현되어 있습니다. 추후 카카오 비즈니스 채널 개설 후 오픈빌더 [스킬 URL] 칸에 위 주소만 입력하면 파트너나 부모님이 카톡방에서 물어볼 때 즉시 현재 상태와 예측 시각을 자동 답변합니다.
