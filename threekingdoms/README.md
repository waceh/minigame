# 삼국지 · 난세의 수호자

Godot 4.5 싱글플레이 RTS 랜덤 디펜스입니다. 서로 다른 이름의 장수 39명, 5단계 성장, 63개 승급·혼합 조합, 선택 판매와 30개 웨이브를 제공합니다.

## 실행과 화면

저장소 루트에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/threekingdoms.html`에 접속합니다. Godot 에디터에서는 이 폴더의 `project.godot`를 엽니다. WebGL 2와 가로 화면을 권장합니다.

전투 화면을 크게 두고 상단에는 자원, 하단에는 미니맵·초상화·선택 부대·명령창을 배치했습니다. 구도 참고: https://www.youtube.com/watch?v=wjHCZjVRGS8 . 검색·등급 필터·장수 카드와 재료 경로 탐색은 https://tmo.gg/g/ord/characters 를 참고했습니다. 참조 게임의 그래픽이나 유닛 데이터는 포함하지 않았습니다.

## 조작

- 클릭: 장수 선택. Shift + 클릭: 추가/해제. 드래그: 부대 선택.
- 더블클릭: 같은 장수 전체 선택. Ctrl+A / Cmd+A: 전체 선택.
- A 후 적 클릭: 지정한 적을 추격·집중 공격. A 후 지면 클릭: 공격 이동. 주변 적과 교전한 뒤 원래 목적지로 계속 이동합니다.
- H: 위치 사수. 움직이거나 추격하지 않고 사거리 안의 적만 공격합니다. 이동·공격 명령으로 해제합니다.
- 우클릭: 이동 / 적 집중 공격. 공격 지정을 기다리는 동안 우클릭·Esc는 지정만 취소합니다.
- 휠: 확대/축소. 방향키: 시점 이동. Home: 초기화. 미니맵 클릭: 해당 지역으로 시점 이동.
- Space: 35금으로 1단계 장수 소환. 모두 중앙 소환진에서 나타나 그 주변으로 모입니다.
- M 또는 승급 버튼: **선택한 부대 안에 있는 동일 장수 3명**으로 다음 단계의 다른 장수를 만듭니다. 선택 밖의 장수는 재료로 쓰지 않습니다.
- 혼합 조합표: 장수·재료 이름 검색, 단계·진영 필터, 선택 재료로 가능한 조합 필터. 재료 이름을 누르면 해당 장수의 획득·사용 경로를 탐색합니다.
- Delete / Backspace 또는 초상화 아래 판매 버튼: 현재 대표 선택 장수 **1명만** 판매. 환급액은 버튼에 표시됩니다.
- N: 다음 진격. Esc: 일시정지. 화면 버튼으로 2배속·전군 훈련을 지원합니다.
- 창 전환 시 자동 일시정지합니다. 도감이 열리면 전투와 명령 단축키가 정지합니다.

## 장수와 성장

글자색은 1단계 흰색, 2단계 초록, 3단계 파랑, 전설 보라, 신화 금색입니다. 전장 이름표는 고정 크기의 화면 글자로 표시하며 어두운 배경과 외곽선을 사용합니다. 하단 장수 이름·정보·승급 대상·조합표에도 같은 등급색을 적용합니다.

각 장수의 이름은 하나의 단계에만 속합니다. 같은 이름에 별을 더하는 방식 대신 승급할 때 장수 자체가 바뀝니다.

| 단계 | 촉 | 위 | 오 |
| --- | --- | --- | --- |
| 1단계 (18명) | 관평·주창·미축·간옹·요화·마대 | 조홍·이전·악진·우금·문빙·만총 | 주태·한당·정보·서성·반장·진무 |
| 2단계 (9명) | 황충·마초·장비 | 하후돈·허저·전위 | 태사자·황개·능통 |
| 3단계 (6명) | 유비·관우 | 조조·장료 | 손권·감녕 |
| 전설 (3명) | 제갈량 | 사마의 | 육손 |
| 신화 (3명) | 조운 | 순욱 | 주유 |

1단계 18명은 균등 확률로 소환합니다. 1·2단계는 같은 장수 3명으로 승급할 수 있습니다. 혼합 조합으로도 획득할 수 있어 하나의 재료가 여러 경로에 쓰입니다. 3단계 이상은 혼합 조합으로 성장합니다. 모든 승급·조합은 현재 선택한 부대 안의 재료를 정확한 수량만 소비하며, 재료 부족 시 아무것도 소비하지 않습니다.

총 63개 경로: 동일 장수 승급 27개, 1단계 재료 혼합 18개, 3단계 혼합 6개, 전설 혼합 6개, 신화 혼합 6개. 예:

- 관평 3명 → 황충. 관평 2명 + 주창 1명 → 황충 경로도 있습니다.
- 2단계 황충 3명 → 3단계 유비. 2단계 황충 + 2단계 장비 + 1단계 관평 2명으로도 유비를 만들 수 있습니다.
- 3단계 조조 + 3단계 장료 → 사마의.
- 사마의 + 3단계 조조 + 2단계 하후돈 2명 + 1단계 조홍 → 신화 순욱.
- 제갈량 + 3단계 유비 + 2단계 황충 2명 + 1단계 마대 → 신화 조운.
- 육손 + 3단계 손권 + 2단계 황개 2명 + 1단계 주태 → 신화 주유.

이전 예시의 1단계 조조 재료는 이름별 단계 고정을 위해 1단계 조홍으로 바뀌었습니다. 각 신화에는 대체 혼합 경로도 있습니다. 전체 재료와 현재 선택 수량은 게임 안의 조합표에서 확인합니다.

## 전투와 자원

초기 군자금 210, 성문 30, 출전 한도 36명입니다. 근접·범위·기절·둔화·화염·궁병·군주 버프를 섞어 배치합니다. 전군 훈련은 최대 10단계로 기본 공격력을 단계당 12% 높입니다. 군주 버프는 중첩되지 않습니다.

판매는 해당 단계의 표준 재료 가치의 70%를 내림하여 환급합니다: 1단계 24금, 2단계 73금, 3단계 220금, 전설 441금, 신화 833금. 혼합 조합과 판매를 반복해 차익을 얻을 수 없도록 검사합니다.

적이 길을 한 바퀴 돌면 일반은 성문 1, 적장은 5를 잃습니다. 적은 장수를 공격하지 않습니다. 5진마다 적장이 나오며 30진 방어 시 승리합니다. 처치와 웨이브 보상으로 금화를 받으며, 다음 진격은 준비 시간 12초 후 자동 시작하거나 N으로 앞당깁니다. 최고 기록은 브라우저/기기에 저장합니다.

## 검증과 빌드

```sh
godot --headless --path threekingdoms --script tests/game_test.gd
godot --headless --path threekingdoms --script tests/merge_test.gd
godot --headless --path threekingdoms --script tests/economy_test.gd
godot --headless --path threekingdoms --script tests/controls_test.gd
godot --headless --path threekingdoms --script tests/orders_test.gd
godot --headless --path threekingdoms --script tests/balance_sim.gd
godot --headless --path threekingdoms --export-pack Web /ABSOLUTE/PATH/minigame/threekingdoms/web/index.pck
```

테스트는 실제 클릭으로 M·판매·조합 버튼, 선택 범위 보호, 정확한 재료 소비, 이름별 단계 고정, 63개 경로 도달 가능성, 판매 차익 방지, A/H 명령, 미니맵·더블클릭, 승패를 검사합니다. 자동 플레이는 3개 시드에서 정상 자원과 실제 명령 함수로 진행하며 모든 전략의 난이도를 보장하지는 않습니다. 테스트는 사용자 최고 기록을 읽거나 쓰지 않습니다.

`jumpking/web/`의 Godot 4.5 런타임을 공유합니다. `web/index.html`은 수동 셸이므로 일반 Web 전체 내보내기로 덮어쓰지 마세요. 갱신할 때 바깥 페이지의 iframe과 안쪽 페이지의 PCK 버전을 함께 올립니다.

자산은 [assets/ART.md](assets/ART.md), 추가 장수·나무의 생성 프롬프트는 [assets/EXPANDED_ART.md](assets/EXPANDED_ART.md), 글꼴 라이선스는 [OFL.txt](OFL.txt)에 있습니다. 프레임별 실제 경계와 발 위치를 이용해 인접 이미지 노출과 포즈별 위치 흔들림을 줄였습니다. PNG 원본은 유지합니다.
