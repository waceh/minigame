# 삼국지 · 난세의 수호자

2D 장수와 고전 RTS 스타일 전장에서 즐기는 Godot 4.5 RTS 랜덤 디펜스입니다. **60개 등급별 장수, 6등급, 51개 단일 조합식, 30웨이브**를 제공합니다.

## 로컬 실행

저장소 루트에서 `python3 -m http.server 8003` 실행 후 `http://127.0.0.1:8003/threekingdoms.html?v=4.8.0`에 접속합니다. Godot에서는 `project.godot`를 엽니다. WebGL 2와 가로 화면을 권장합니다.

이번 수정은 사용자 검토용 로컬 변경입니다. 공개 배포와 커밋·푸시는 별도 승인이 있어야 합니다.

## 화면과 조작

- 전투 화면은 1280×578, 하단 HUD는 168px입니다. 4.4 스타일 석재·금속 프레임 질감을 복원하고 초상화·명령 버튼을 작은 패널에 맞췄습니다.
- 왼쪽 클릭: 선택. Shift+클릭: 추가/해제. 왼쪽 드래그: 부대 선택. A 공격 지정 중 좌클릭은 공격 이동입니다.
- 오른쪽 클릭: 이동 또는 적 집중 공격. **A 후 왼쪽 클릭**은 공격 이동/지정 공격입니다. Esc는 공격 지정을 취소합니다.
- 더블클릭: 같은 등급·장수 전체 선택. Ctrl/Cmd+A: 전군 선택. H: 위치 사수.
- Space: 35금 소환. 소환 장수는 중앙 소환진에서 합류합니다.
- 우측 12칸 중 아래 두 줄: 선택한 기준 유닛으로 만드는 다음 조합만 표시합니다. 아이콘 클릭으로 조합하고 마우스를 올리면 등급별 색상의 재료 안내가 나옵니다. M키: 전체 단일 조합표.
- Tab/F8 또는 우측 명령창 첫 칸: 도감.
- U키 또는 본영 건물 클릭: 전군 공격력·소환 확률 연구. 모든 메뉴를 열어도 전투는 계속됩니다.
- Delete/Backspace: 대표 선택 장수 1명 판매. N: 진격 시작. Esc: 창 닫기/명령 취소/선택 해제.
- 휠 확대/축소, 방향키 시점 이동, Home 초기화. 미니맵 클릭은 시점만 이동합니다.

## 등급과 단일 조합

| 등급 | 수량 | 예시 |
| --- | ---: | --- |
| 흔함 | 9 | 관평·주창·미축 / 조홍·이전·악진 / 주태·한당·정보 |
| 안흔함 | 18 | 황충·마초·장비 / 하후돈·허저·전위 / 태사자·황개·능통 |
| 희귀 | 15 | 유비·관우 / 조조·장료 / 손권·감녕 |
| 전설 | 3 | 제갈량·사마의·육손 |
| 히든 | 6 | 조운·관우 / 순욱·조조 / 주유·손권 |
| 초월 | 9 | 조운·관우·제갈량 / 조조·순욱·사마의 / 주유·손권·육손 |

**등급+이름**이 장수의 식별자입니다. 희귀 조조·히든 조조·초월 조조는 별도 재료이고 공격력·속도·사거리·공격 유형도 다릅니다.

조합 결과마다 조합식은 정확히 하나입니다. 이전의 동일 장수 3명 자동 승급과 대체 혼합 조합을 제거했습니다. 허저 3명 또는 전위 3명으로 장료를 만드는 경로는 없습니다. 모든 조합은 [단일 조합표](RECIPES.md)에 기록되어 있으며 게임의 `roster.gd`와 일치합니다.

예시:

- 장료(희귀) = 전위(안흔함) + 허저(안흔함) + 이전(흔함)
- 조조(히든) = 사마의(전설) + 장료(희귀) + 허저(안흔함)
- 조조(초월) = 조조(히든) + 사마의(전설) + 허저(안흔함)

조합표는 **보유 부대 전체**에서 재료를 계산하고 정확한 수량만 소비합니다. 조합 대상이 아닌 장수는 남깁니다. 선택한 장수가 실제 재료이면 그 위치에서 결과가 합류하며, 아니면 첫 재료의 위치를 사용합니다. 재료가 부족하거나 일시정지 상태이면 아무것도 소비하지 않습니다. 같은 이름의 낮은 등급을 높은 등급 재료로 대신 쓸 수 없습니다.

결과·재료에는 등급, 초상화, 보유/필요 수량을 함께 표시합니다. 이름·등급·진영 검색과 지금 조합 가능 필터를 지원합니다. 재료를 클릭하면 해당 **등급** 장수의 관련 조합만 표시합니다.

표 형태 참고: https://ordsearch.net/mix/helper . 그래픽·유닛·조합 재료는 삼국지 프로젝트의 자체 데이터입니다.

## 전투와 자원

초기 금화 210, 성문 30, 병력 한도 36명입니다. 소환 확률은 흔함 80% / 안흔함 17% / 희귀 3%입니다. 등급별 후보는 균등 추첨하며 히든·초월은 소환으로 나오지 않습니다.

전군 공격력 강화는 최대 10단계이며 단계당 기본 공격력 +12%, 비용은 80+현재 단계×55금입니다. 소환 연구도 최대 10단계로 안흔함 +1%p·희귀 +0.3%p씩 증가하고, 비용은 60+현재 단계×40금입니다. 최대 확률은 67% / 27% / 6%입니다. 군주 버프는 중첩되지 않습니다.

판매는 실제 투입 금화의 70%를 내림하여 돌려줍니다. 직접 소환은 등급과 무관하게 24금이며, 조합 장수는 실제 소비 재료의 투입 금화를 합산합니다. 도감의 표준 재료가치는 단일 조합식을 재귀적으로 계산한 값입니다.

적이 길을 한 바퀴 돌면 일반은 성문 1, 적장은 5를 잃습니다. 적은 장수를 공격하지 않습니다. 5진마다 적장, 30진 방어 시 승리합니다. 처치와 웨이브 보상으로 금화를 받으며 준비 시간 12초 후 다음 진격을 자동 시작합니다. 최고 기록은 브라우저/기기에 저장합니다.

## 캐릭터와 아트

흔함 장수 9명은 모두 개별 이미지 행을 사용합니다. 주창은 투구 없는 수염 무장과 언월도, 조홍은 검·방패, 정보는 백발 노장과 창·방패, 악진은 붉은 머리띠·갑옷·쌍검으로 구분합니다. 악진의 공격도 책사의 둔화 대신 근접 무장 공격입니다.

이미지 파일·생성 프롬프트: [흔함 장수 아트](assets/COMMON_ART.md), [주요 장수 아트](assets/CHIBI_ART.md). 원본 RGBA 이미지는 그대로 보존하고 `frames.gd`의 프레임·발 기준점을 사용합니다. 글꼴 라이선스는 [OFL.txt](OFL.txt)입니다.


검사는 조합식 유일성·순환 없음·60개 장수 도달 가능성·등급 재료 구분·실제 버튼 조합·정확한 재료 소비·판매 차익 방지·강화·선택/이동·승패를 다룹니다. 자동 플레이는 세 시드의 참고 결과이며 모든 전략의 난이도를 보장하지는 않습니다. 테스트는 사용자 최고 기록을 읽거나 쓰지 않습니다.

웹 런타임은 `jumpking/web/`의 Godot 4.5 파일을 공유합니다. `web/index.html` 수동 셸을 전체 Web 내보내기로 덮어쓰지 마세요. 수정 후 웹 팩을 빌드하고 바깥 iframe과 안쪽 mainPack 버전을 함께 올립니다. 로컬 파일 수정만으로 공개 사이트가 바뀌지는 않습니다.

### 로컬 RTS 그래픽 변경 (4.6.2)
절차적 잔디·석재 도로·벽돌·기와 재질, 기존 참나무 자산, 자연광과 어두운 강물로 전장을 조정했습니다. S는 정지 후 자동 교전, H는 위치 사수입니다. 전장 가장자리에서 카메라를 이동합니다. 좌클릭 선택 / 우클릭 이동은 유지됩니다.

4.6.3: A 또는 공격 버튼 → 지면 좌클릭으로 공격 이동, 적 좌클릭으로 집중 공격합니다. 일반 좌클릭은 선택, 일반 이동은 우클릭입니다.

4.6.4: 장수 선택 시 우측에 해당 등급·장수를 재료로 쓰는 조합만 자동 표시합니다. 보유/필요 수량과 조합 버튼을 제공하며, 조합 후 새 장수 기준으로 갱신합니다.

4.6.5: 낮은 세 등급의 장수 크기를 축소했습니다. 도착 후 충돌 보정과 이동이 서로 맞서는 떨림, 미세한 좌우 반전, 과한 걷기 흔들림을 줄였습니다. 가장자리에서도 대형 간격을 유지하며, 스프라이트 프레임마다 독립된 밉맵을 사용합니다.

4.6.6: 우측 세로 조합창을 제거하고 우측 하단 4×3 명령창으로 변경했습니다. 아래줄 왼쪽 두 칸은 선택한 등급·장수를 직접 재료로 쓰는 조합 결과 아이콘입니다. 후속 단계의 조합은 표시하지 않습니다. 재료 부족 시에도 결과 아이콘은 보이며 툴팁으로 보유/필요 수량을 확인합니다. 직접 조합이 세 개 이상이면 아래줄 오른쪽 화살표로 넘깁니다.

4.7.0: 상단 A/H/일시정지 버튼과 하단 전체 조합표/업그레이드/진격 버튼을 제거했습니다. 진격은 상단으로 이동하고 하단 전역 버튼은 소환만 남겼습니다. 조합표는 M, 업그레이드는 건물 또는 U로 열립니다. 메뉴를 열거나 창 포커스가 바뀌어도 전투는 계속됩니다. 조합 툴팁의 유닛 이름에는 등급별 색상을 적용하고 성문·벽돌 장식은 이동 경로 밖으로 옮겼습니다.

4.7.1: 참고 화면에 맞춰 하단을 미니맵 240px / 초상화 168px / 정보 560px / 명령창 312px로 재배치했습니다. 별도 소환 패널을 제거하고 정보창 안에 104×30px 소환 버튼을 배치했습니다. 명령창 12칸은 4×3 구조를 유지합니다.

4.7.3: 우측 12칸 첫 줄은 도감/공격/정지/사수이며 아래 두 줄 8칸은 선택 유닛의 직접 조합 결과입니다. 이동·관련 조합 버튼과 페이지 버튼을 제거했습니다. 일반 이동은 우클릭을 사용합니다.

4.7.4: 흔함 9종의 직접 조합을 각각 2~3개로 제한했습니다. 상위 등급 조합에서 흔함을 반복 요구하던 재료를 제거했으며, 모든 42종의 도달 가능성과 결과별 유일 조합식은 유지합니다. 변경 조합 전체는 RECIPES.md에 기록했습니다.

4.7.5: 각 조합에 기준 유닛을 지정했습니다. 하단 조합 아이콘은 기준 유닛에서만 보이며 보조 재료 유닛에는 나타나지 않습니다. 툴팁에 기준 유닛을 표시하며 결과는 기준 유닛의 위치에서 생성됩니다. 전체 기준 목록은 RECIPES.md를 참조하세요.

4.8.0: 사용자가 제공한 원랜디 4.1 엑셀을 참고해 60종/51개 단일 조합으로 확장했습니다. 흔함 기준 유닛별 두 갈래, 2인 조합·동일 유닛 누적 성장·혼합 등급 상위 조합을 제공합니다. 새 등급 장수 18종은 기존 장수의 외형을 등급별 크기로 재사용합니다. 상세 재료와 기준은 RECIPES.md에 기록했습니다.

4.8.1: 안흔함 허저를 희귀 장료, 희귀 허저를 히든 순욱 조합의 기준 유닛으로 지정했습니다. 툴팁은 불투명한 어두운 배경·테두리·17px 글자·넓은 줄 간격으로 가독성을 높였습니다.
